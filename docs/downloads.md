# Downloads

Not every student has reliable internet, and some classrooms need paper copies. Every chapter is available as a free, printable PDF.

- The PDFs include the full text, the clinical cases, the practice questions **with their answers shown**, and a screenshot of each simulation with a link to the interactive version.
- The interactive simulations themselves only run on the website.
- Version 1.1, October 2026. If the website changes after this date, the website is the most up-to-date version.
