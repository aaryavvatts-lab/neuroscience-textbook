# Contact

## Found a mistake?

Accuracy matters a lot in a science and medicine book. If you spot an error, a broken link, or a simulation that doesn't work, please open an issue on GitHub:

**[Report an issue on GitHub](https://github.com/aaryavvatts-lab/neuroscience-textbook/issues)**

Please include:

- The chapter and section (or the simulation name)
- What's wrong, and a source for the correction if you have one
- Your browser and device, if it's a simulation problem

## Want to contribute?

Teachers, students, and scientists are welcome to suggest improvements, new practice questions, new simulations, or translations. Open an issue to discuss your idea, or fork the [repository](https://github.com/aaryavvatts-lab/neuroscience-textbook) and send a pull request.
