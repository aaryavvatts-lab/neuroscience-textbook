# How to Cite This Book

If you use this book in a class, a paper, a lesson plan, or a project, please cite it.

**Permanent DOI (all versions):** [https://doi.org/10.5281/zenodo.23353113](https://doi.org/10.5281/zenodo.23353113). The book is archived on Zenodo, so this link will keep working even if the website moves.

Author ORCID: [0009-0006-3333-0809](https://orcid.org/0009-0006-3333-0809)

**APA (7th edition)**

Sharma, A. (2026). *From neuron to bedside: An interactive neuroscience textbook for high school students and future doctors*. https://doi.org/10.5281/zenodo.23353113

**MLA (9th edition)**

Sharma, Aaryav. *From Neuron to Bedside: An Interactive Neuroscience Textbook for High School Students and Future Doctors*. 2026, aaryavvatts-lab.github.io/neuroscience-textbook/.

**Chicago (17th edition)**

Sharma, Aaryav. 2026. *From Neuron to Bedside: An Interactive Neuroscience Textbook for High School Students and Future Doctors*. https://aaryavvatts-lab.github.io/neuroscience-textbook/.

**BibTeX**

```bibtex
@book{sharma2026neuron,
  title     = {From Neuron to Bedside: An Interactive Neuroscience Textbook
               for High School Students and Future Doctors},
  author    = {Sharma, Aaryav},
  year      = {2026},
  version   = {1.1.1},
  doi       = {10.5281/zenodo.23353113},
  url       = {https://aaryavvatts-lab.github.io/neuroscience-textbook/},
  license   = {CC BY-NC-SA 4.0},
  note      = {Open, interactive intelligent textbook}
}
```

To cite a single chapter, add the chapter title and its URL. For example:

Sharma, A. (2026). Chapter 2: The action potential. In *From neuron to bedside*. https://aaryavvatts-lab.github.io/neuroscience-textbook/chapters/02-action-potential/
