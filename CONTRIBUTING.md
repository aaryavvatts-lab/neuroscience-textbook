# Contributing to From Neuron to Bedside

Thank you for helping make this free neuroscience textbook better. Students, teachers, scientists, and clinicians are all welcome.

## Ways to help

- **Report a mistake.** Use the [Report a mistake](https://github.com/aaryavvatts-lab/neuroscience-textbook/issues/new?template=1-error-report.yml) form. Please include a reliable source for the correction if you can.
- **Tell us you used it.** If you used the book in a class, club, or study group, the [I used this book](https://github.com/aaryavvatts-lab/neuroscience-textbook/issues/new?template=2-classroom-use.yml) form helps decide what to improve next.
- **Review a chapter.** If you have expertise in neuroscience, medicine, or teaching, the [Volunteer to review a chapter](https://github.com/aaryavvatts-lab/neuroscience-textbook/issues/new?template=4-expert-review.yml) form is the best way to help. Reviewers who agree are credited by name.
- **Suggest an idea**, like new practice questions, simulations, or translations, with the [Suggest an improvement](https://github.com/aaryavvatts-lab/neuroscience-textbook/issues/new?template=3-suggestion.yml) form.

## Editing the book yourself

1. Fork the repository and create a branch.
2. Install the tools: `pip install -r requirements.txt`
3. Preview your changes: `mkdocs serve`, then open http://127.0.0.1:8000/neuroscience-textbook/
4. Before you open a pull request, make sure `mkdocs build --strict` finishes with no warnings.
5. Open a pull request that explains what you changed and why, with sources for any factual change.

## Accuracy rules

These rules keep the book trustworthy. Please follow them in every contribution.

- Every statistic, date, drug or device approval, and study claim needs a source you have actually opened. Prefer NIH, CDC, FDA, and peer-reviewed research.
- Never invent a citation, a number, or a quote.
- Drug and device approval status must be exact ("accelerated approval," "cleared," "investigational," and so on).
- No medication doses and no personal medical advice.
- Bedside cases are fictional composites unless they are clearly identified as historical.
- Use person-first or identity-first language as the community in question prefers, and avoid stigmatizing words.
- Don't copy text or figures from copyrighted books, including the SfN *Brain Facts* book.

The full house rules are in [CLAUDE.md](CLAUDE.md) and [EDITOR_DOMAIN.md](EDITOR_DOMAIN.md).

## Writing style

- Write for a high school student with one year of biology. Define every term before you use it.
- Use plain words and short paragraphs. Don't use em dashes.
- Don't change existing headings, because other pages link to them.
